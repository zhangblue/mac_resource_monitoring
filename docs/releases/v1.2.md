# Mac Resource Monitor v1.2

发布日期：2026 年 10 月 20 日

本次更新让菜单栏与详情面板按需显示监控模块，完善设置页布局，并修复模块开关切换后的首页留白问题。

## ✨ 更新亮点

- **按需监控**：CPU、内存、上传、下载、芯片温度、风扇、磁盘容量支持独立开启或隐藏，选择自动保存。
- **更紧凑的设置页**：模块按钮采用三列布局；左上角显示标题，左下角返回首页，右下角退出应用。
- **更稳定的首页布局**：模块关闭后重新开启，首页按当前内容重新排列卡片和计算高度。

## 🚀 新功能

- CPU、内存、上传、下载开关同时控制菜单栏摘要、详情卡片、趋势与进程排行；温度、风扇、磁盘容量开关控制对应详情卡片。
- 未选中的指标停止独立采集；其他已启用指标仍需要的共享采集继续运行。
- 支持关闭全部模块，菜单栏保留“监控”入口，可随时进入设置重新开启。

## 🔧 改进

- 模块按钮缩小至 28 pt 高，保留开启高亮、关闭灰色及辅助功能状态。
- 设置标题与首页标题统一字体和边距；底部按钮保持固定，不随设置内容滚动。
- 模块选择在启动时恢复；重新开启速率指标时先建立采样基线，再显示新的速率与历史。
- 保留单项采集故障隔离，某个模块暂不可用时其余指标继续刷新。

## 🐛 修复

- 修复隐藏模块后重新开启、返回首页时出现多余空白的问题。
- 修复只显示磁盘容量时仍预留空网格行的问题。
- 防止设置切换期间的旧采样结果恢复已隐藏的指标与历史数据。

| 文件 | 用途 |
| --- | --- |
| [MacResourceMonitor.dmg](https://github.com/zhangblue/mac_resource_monitoring/releases/download/v1.2/MacResourceMonitor.dmg) | 可直接安装的 Apple Silicon 版本 |
| [MacResourceMonitor.dmg.sha256](https://github.com/zhangblue/mac_resource_monitoring/releases/download/v1.2/MacResourceMonitor.dmg.sha256) | 安装包 SHA-256 校验文件 |
| Source code | 源码压缩包，需自行编译 |

系统要求：**Apple Silicon Mac，macOS 13 或更高版本**。

打开 DMG，将 `MacResourceMonitor.app` 拖到 `Applications` 快捷方式。首次运行时，在“应用程序”中右键点击应用并选择“打开”；如系统仍阻止启动，可在“系统设置”→“隐私与安全性”中确认打开。详细步骤见[安装指南](https://github.com/zhangblue/mac_resource_monitoring/blob/v1.2/INSTALL.md)。

## 已知限制

- 应用采用 ad-hoc 签名，尚未经过 Apple 公证，无需关闭 Gatekeeper。
- 本版仅提供 arm64 构建，不支持 Intel Mac。
- 芯片温度与风扇数据取决于设备支持情况，不可用时显示“暂不可用”。
