# Mac Resource Monitor v1.0

发布日期：2026 年 10 月 12 日

首个正式版本，提供轻量的 macOS 菜单栏资源监控，打开面板即可查看系统负载、网络流量和历史趋势。

## ✨ 更新亮点

- **菜单栏实时总览**：显示 CPU、内存、网络上传与下载摘要，不在 Dock 中常驻图标。
- **交互趋势图**：查看 CPU、内存、上传和下载历史，支持动态纵轴、参考线与鼠标悬停数值提示。
- **可调整的监控设置**：提供 1/3/5 秒刷新间隔和 1/5/10 分钟历史窗口，自动保存选择。

## 🚀 首发功能

- 详情面板显示芯片温度、风扇状态，以及系统启动卷的已用容量与总容量。
- 默认每 1 秒刷新，保留最近 5 分钟趋势；历史数据随所选时间窗口裁剪。
- 设置页支持登录时自动启动，并提供版本信息与本地诊断日志位置。
- 提供应用图标和 DMG 安装包，支持拖拽安装。

## 🔧 稳定性与体验

- 单项采集失败时隔离该项，其他指标继续刷新。
- 睡眠唤醒后重建 CPU 和网络速率基线，避免将睡眠时长计入速率。
- 趋势纵轴根据当前可见样本调整；缺失样本保留断点，处理时间回拨和配置变化后的历史窗口。
- 磁盘监控仅显示容量，不采集磁盘读写速率。

## 📦 下载与安装

| 文件 | 用途 |
| --- | --- |
| [MacResourceMonitor.dmg](https://github.com/zhangblue/mac_resource_monitoring/releases/download/v1.0/MacResourceMonitor.dmg) | 可直接安装的 Apple Silicon 版本 |
| [MacResourceMonitor.dmg.sha256](https://github.com/zhangblue/mac_resource_monitoring/releases/download/v1.0/MacResourceMonitor.dmg.sha256) | 安装包 SHA-256 校验文件 |
| Source code | 源码压缩包，需自行编译 |

系统要求：**Apple Silicon Mac，macOS 13 或更高版本**。

打开 DMG，将 `MacResourceMonitor.app` 拖到 `Applications` 快捷方式。首次运行时，在“应用程序”中右键点击应用并选择“打开”；如系统仍阻止启动，可在“系统设置”→“隐私与安全性”中确认打开。详细步骤见[安装指南](https://github.com/zhangblue/mac_resource_monitoring/blob/v1.0/INSTALL.md)。

## 已知限制

- 应用采用 ad-hoc 签名，尚未经过 Apple 公证，无需关闭 Gatekeeper。
- 本版仅提供 arm64 构建，不支持 Intel Mac。
- 芯片温度与风扇数据取决于设备支持情况，不可用时显示“暂不可用”。
