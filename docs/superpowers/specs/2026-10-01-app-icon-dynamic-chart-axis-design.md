# 应用图标与动态折线图纵轴设计

日期：2026-10-01

## 1. 目标

为 Mac Resource Monitor 增加正式应用图标，并为 CPU、内存、上传和下载的最近五分钟折线图增加可读的动态纵坐标。动态坐标必须突出低负载时的细小波动，不能因为固定使用 `0%～100%` 等过大范围而把曲线压成近似直线。

## 2. 应用图标

图标采用已确认的 macOS 工具类风格：

- 深色圆角方形主体，跟随现代 macOS 应用图标的视觉比例。
- 中心使用蓝色到绿色渐变的性能折线，并辅以低对比度网格或仪表元素。
- 不包含文字、数字、品牌缩写或复杂装饰，确保在菜单栏搜索结果和小尺寸列表中仍可辨认。
- 输出一份 1024×1024 PNG 源图，并生成包含 macOS 标准尺寸的 `.icns` 文件。

应用包通过 `CFBundleIconFile` 引用图标。构建脚本负责将 `.icns` 复制到应用包的 `Contents/Resources`，使源码构建和 DMG 交付使用同一图标。应用仍为纯菜单栏应用，图标不会改变“不显示 Dock 图标”的既有行为。

## 3. 折线图视觉设计

四张趋势图保持现有两列卡片布局，但为纵坐标和曲线预留更多高度与左侧空间：

- 纵坐标显示上、中、下三档刻度，不显示横坐标文字。
- 仅保留三条轻量水平参考线，避免网格喧宾夺主。
- CPU 使用蓝色，内存使用紫色，上传使用橙色，下载使用绿色。
- CPU、内存刻度使用百分比；上传、下载根据数量级自动使用 `B/s`、`KB/s`、`MB/s` 或 `GB/s`。
- 缺失采样仍按现有规则断开曲线，不以零值补齐。
- 单个有效采样继续显示为点，多个连续采样显示为线。

## 4. 动态纵轴算法

每个指标只使用当前最近五分钟内的有限有效值计算显示范围。纵轴由独立、可测试的展示模型产生，界面只负责渲染计算结果。

### 4.1 CPU 与内存

1. 取窗口内最小值和最大值。
2. 以二者中心为轴心，上下加入约 10% 的视觉留白。
3. 显示范围的最小跨度为 10 个百分点。即使 CPU 只在 `2%～5%` 间变化，也会得到约 `0%～10%` 的范围，而不是固定 `0%～100%`。
4. 最终范围限制在 `0%～100%`。触及一侧边界时，向另一侧补足最小跨度。
5. 将上下界和中间刻度整理为易读的百分比数值。

### 4.2 上传与下载

1. 取窗口内最小值和最大值，不强制纵轴从零开始；持续存在的低幅波动仍应清晰可见。
2. 上下加入约 10% 留白，最低值不得小于零。
3. 当所有值相同或差值过小时，使用当前值约 20% 的跨度；接近零时使用一个很小但非零的速率跨度，避免零高度坐标域。
4. 刻度间隔从 `1、2、5 × 10ⁿ` 中选择，生成下、中、上三档易读刻度。
5. 三个刻度共享同一单位，单位按上界数量级选择，避免同一纵轴混用多种单位。

### 4.3 数据不足与异常值

- 没有有效点时保持当前空状态，不显示虚构坐标。
- 只有一个有效点时仍生成安全的非零范围并显示点。
- 忽略 `NaN` 和无穷值。
- 极端瞬时峰值在其仍处于五分钟窗口内时必须包含在坐标域中；离开窗口后范围自动恢复。
- 坐标范围变化应直接反映当前窗口数据，不改变底层采样值或历史缓存。

## 5. 代码与测试边界

预计改动范围：

- `SparklineView`：显示纵轴、参考线、颜色与动态 Y 轴范围。
- `MetricCardView` 和 `DashboardView`：传入指标类型、颜色与单位格式。
- 展示模型：新增动态范围和刻度计算，避免把算法写在 SwiftUI `body` 中。
- `Resources/Info.plist`、资源目录和构建脚本：打包应用图标。

自动化测试至少覆盖：

- CPU 低负载波动不会落入 `0%～100%` 固定范围。
- 百分比范围的最小跨度、上下边界和恒定值。
- 网络范围不强制从零开始、恒定值、接近零值和易读刻度。
- 空数据、单点、缺失值以及非有限值。
- 四种指标颜色和格式配置正确。
- Release 应用包包含图标资源，`Info.plist` 的图标键指向存在的文件。

## 6. 验收标准

- Finder、访达安装窗口和应用信息中显示新图标。
- CPU 在约 `2%～5%` 的低负载波动下，折线仍有明显起伏。
- 四张折线图均显示三档纵坐标，刻度与指标单位一致且不被裁切。
- 动态缩放不改变五分钟时间窗、断线规则和 300 点历史容量。
- 浅色与深色外观下曲线、坐标文字和参考线均清晰可读。
- 全部自动化测试、Release 构建与 DMG 发布验证通过。

## 7. 范围外

- 不增加横坐标时间标签或图表交互提示。
- 不新增温度、风扇或磁盘容量折线图。
- 不改变采样频率、菜单栏文字、磁盘统计口径或 Intel 支持范围。
- 不改变签名、公证和 App Store 发布策略。
